# Embodied Frontier · 具身前沿机器人社区

**Embodied Frontier Robot Community** — 一个关于具身智能与机器人的开放探索分享站。

> Where embodied intelligence meets the frontier.

## 内容板块

- **产业动态**（SYS.01 · Industry Pulse）：按月梳理 2026 具身智能产业关键节点与代表玩家
- **前沿技术科普**（SYS.02 · Frontier Lab）：VLA、世界模型、触觉、端侧推理等关键技术直白解读
- **机器人图鉴与创作交流**（SYS.03 · Robot Archive & Exchange）：按形态梳理具身机器人生态 + 社区创作投稿
- **探索日志**（SYS.04 · Field Notes）：实验室手记式的个人探索记录

## 技术说明

- 纯静态单页站点（原生 HTML/CSS/JS，无构建依赖）
- 配图为 AI 生成示意图，不代表任何具体产品
- 内容基于公开报道整理，仅供学习交流，具体以厂商官方发布为准

## 部署

站点通过 GitHub Actions 自动部署到 GitHub Pages（见 `.github/workflows/pages.yml`）。
